# 华师统一身份认证（SSO）接入指南

本文档说明如何把 lab_bot 从「mock 登录」切换到「华南师范大学统一身份认证平台」，
依据《华南师范大学统一身份认证平台接入说明文档》（OAuth2.0）。

后端代码已按 OAuth2 协议改造完成，**三档环境只靠 `.env` 切换，不改代码**：

```
mock(本地，无需凭据)  →  测试环境(联调)  →  生产环境(上线)
```

## 二、登录流程（小程序场景，文档 3.2.1）

```
小程序 wx.login 拿微信 code
   │
   ├─ 调后端 GET /api/auth/sso/applet-login-url?code=<微信code>  → 得到统一认证 URL
   │
   ├─ 用 web-view 打开该 URL（/openapi/wechat_applet.html）
   │     用户在统一认证平台登录 → 平台回调 redirect_uri 带回一次性 code（5 分钟）
   │
   ├─ 回调命中后端 GET /api/auth/sso/callback?code=<授权code>
   │     后端：code → token.html 换 access_token → userinfo.html 取用户信息
   │            → 映射用户（account→学工号, dept→学院, kindCode→角色）→ 签发 JWT
   │
   └─ 后端重定向到 /sso-bridge?token=... ，前端在 web-view 中转页把 token 传回小程序并关闭 web-view
```

字段映射（userinfo.html → 本系统 User）：

| SSO 返回 | 本系统字段 | 说明 |
|---|---|---|
| `account` | `sso_id` | 学工号（一卡通号） |
| `name` | `name` | 姓名 |
| `dept` | `college` | 所在单位 |
| `kindCode` | `role` | 前四位映射：1001/1002→teacher，1003/1004→student |
| `openid` | `openid` | 小程序 openid |

> 命中 `ADMIN_SSO_IDS` 白名单的学工号，登录即自动提升为 `admin`。

## 三、`.env` 配置：三档环境怎么填

### 档位 A：mock（当前，无需任何凭据）
```env
SSO_MOCK=true
```
走本地模拟登录 + `/api/auth/dev-login`，业务功能照常调试。**审批没下来之前一直用这档。**

### 档位 B：测试环境（拿到审批回执后联调）
```env
SSO_MOCK=false
SSO_BASE_URL=<回执邮件给的测试环境认证服务地址>     # 例：https://test-sso.scnu.edu.cn/AccountService
SSO_SERVICE_URL=https://你的已备案域名/api/auth/sso/callback
SSO_CLIENT_ID=<回执给的测试 client_id>
SSO_CLIENT_SECRET=<回执给的测试 client_secret>
SSO_APPLET_ID=<你的小程序 APPID>                  # 通常与 WECHAT_APPID 相同
WECHAT_MOCK=false
WECHAT_APPID=<小程序 APPID>
WECHAT_SECRET=<小程序 Secret>
```

### 档位 C：生产环境（联调通过后上线）
同档位 B，但换成生产值：
```env
SSO_MOCK=false
SSO_BASE_URL=https://sso.scnu.edu.cn/AccountService   # 生产认证服务地址
SSO_CLIENT_ID=<生产 client_id>
SSO_CLIENT_SECRET=<生产 client_secret>
# 其余同上
```

> 切换后重启服务即可生效：`docker compose up -d --build`（改了 .env 也可 `docker compose up -d` 重建容器）。

## 四、首次接入操作步骤（拿到凭据后）

1. **填 `.env`**：按上面「档位 B」填测试环境凭据。
2. **注册小程序到 SSO**（一次性，文档 3.3.1）：
   ```bash
   cd backend
   python register_sso_applet.py "实验室助手"   # 引号内为小程序名称
   ```
   返回 `msgcode=0` 即注册成功。
3. **小程序后台配置**（mp.weixin.qq.com → 开发管理）：
   - 「request 合法域名」：加 `https://你的域名`
   - 「业务域名」：加 web-view 页面所在域名，并按提示**下载校验文件放到服务器根目录**
4. **前端登录页**：实现 web-view 登录中转页（详见第六节，待补）。
5. **联调**：真机调试 → 走统一认证登录 → 确认能用真实学工号登录、角色正确。
6. **切生产**：把 `.env` 换成生产凭据 + `SSO_BASE_URL` 生产地址 → 重启 → 上线体验版/正式版。

## 五、相关后端接口

| 接口 | 方法 | 用途 |
|---|---|---|
| `/api/auth/sso/applet-login-url?code=<微信code>` | GET | 小程序：返回 web-view 要打开的统一认证 URL |
| `/api/auth/sso/login-url` | GET | Web 应用：浏览器跳转登录地址 |
| `/api/auth/sso/callback?code=<授权code>` | GET | 统一认证回调：换 token、取用户信息、签发 JWT |
| `/api/auth/wechat-login` | POST | 已绑定 openid 的老用户：用 wx.login code 直接登录 |
| `/api/auth/dev-login` | POST | **仅 mock**：本地调试登录 |
| `/api/auth/me` | GET | 取当前登录用户 |

代码位置：`backend/app/services/sso.py`、`backend/app/api/auth.py`、`backend/app/core/config.py`。
