# 备案 + HTTPS + 体验版 上线手册

目标：让小程序能**长期、稳定、多人**测试，不依赖你的电脑。
路径：买域名 → 备案 → 服务器配 HTTPS → 小程序填合法域名 → 传体验版。

服务器公网 IP：`175.178.149.40`（腾讯云轻量，广州）

---

## 阶段 1：买域名（10 分钟，你做）

1. 腾讯云控制台搜「**域名注册**」，买一个便宜域名（`.com` 约 ¥55/年，`.cn` 更便宜）。
   - **强烈建议在腾讯云买**：和服务器同账号，备案最顺。
2. 买完做**域名实名认证**（身份证），等几分钟～几小时通过。实名没过不能备案。

---

## 阶段 2：ICP 备案（核心，等待期长，你做）

> 备案是把「域名 ↔ 你这台大陆服务器」在工信部登记，**大陆服务器对外提供网页服务必须备案**，绕不开。

1. 腾讯云控制台搜「**网站备案 / ICP 备案**」，进备案小程序/控制台。
2. 按引导填：
   - 选你这台**轻量服务器**（系统会校验你有可用的「备案授权码」，轻量服务器一般自带，没有就在轻量控制台领）。
   - 主体信息（个人备案填你自己身份证）。
   - 网站信息（域名、服务内容选「其他」或合适分类）。
3. 提交后流程：腾讯云初审（1～2 天）→ 工信部短信核验 → 管局审核（**各省不同，约 3～20 天**，广东一般一周左右）。
4. **收到「备案号」即备案成功。** 这段时间你没法用域名对外，但**服务器和后端照常自测不受影响**。

> ⏳ 这一步是整个流程最慢的，越早提交越好。等待期间继续用真机调试测功能。

---

## 阶段 3：域名解析到服务器（备案通过后，5 分钟，你做）

1. 腾讯云「**DNS 解析 DNSPod**」→ 你的域名 → 添加记录：
   - 记录类型 **A**，主机记录 `@`（或 `api`），记录值 **175.178.149.40**。
   - 想用 `api.你的域名` 就把主机记录填 `api`，后面合法域名也用这个。
2. 等几分钟生效。

---

## 阶段 4：申请 + 部署 HTTPS 证书（备案通过后，服务器端，我已备好框架）

### 4.1 申请免费证书（你做）
腾讯云控制台搜「**SSL 证书**」→ 申请**免费 DV 证书**（绑定你备案好的域名）→ 审核几分钟～几小时通过 → **下载「Nginx」版本**，得到两个文件：
- `xxx_bundle.crt`（证书）
- `xxx.key`（私钥）

### 4.2 放到服务器（你做）
把这两个文件传到服务器 `lab_bot/deploy/nginx/certs/`，并重命名：
```bash
# 在 lab_bot/deploy/nginx/certs/ 目录下
mv xxx_bundle.crt fullchain.pem
mv xxx.key        privkey.pem
```
> 上传方式：OrcaTerm 支持拖拽上传文件；或用 `scp`；或直接 `vim` 粘贴内容。

### 4.3 启用 Nginx 配置（你做）
```bash
cd lab_bot
git pull                                   # 拉取我新增的 nginx 物料
cp deploy/nginx/conf.d/lab_bot.conf.example deploy/nginx/conf.d/lab_bot.conf
# 编辑 lab_bot.conf，把 your.domain.com 全部替换成你的真实域名
```

### 4.4 起 HTTPS（你做）
```bash
docker compose -f docker-compose.yml -f docker-compose.https.yml up -d
```
然后**放行防火墙 80、443 端口**（腾讯云轻量防火墙，跟之前放 8000 一样）。

验证：浏览器打开 `https://你的域名/health`，返回 `{"status":"ok",...}` 且地址栏是**小锁🔒**即成功。

---

## 阶段 5：小程序配置合法域名 + 传体验版（你做）

1. **公众平台**(mp.weixin.qq.com) → 开发 → 开发管理 → **服务器域名** → 把
   `https://你的域名` 填进「**request 合法域名**」。
2. 微信开发者工具里把 `miniprogram/app.js` 的 `baseUrl` 改成：
   ```
   https://你的域名
   ```
   （这次是 https + 域名，不再是 http + IP）
3. 开发者工具点「**上传**」→ 填版本号 → 上传成功后到公众平台「版本管理 → 开发版本」**设为体验版**。
4. 公众平台 → 用户身份 → **体验成员** → 添加同学的微信号。
5. 生成**体验版二维码**发给体验成员 → 他们随时扫、随时测,**不再依赖你电脑，二维码长期有效**。
