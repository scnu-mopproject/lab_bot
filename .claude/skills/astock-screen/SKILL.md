# A 股选股打分 Skill

对每只股票的最新交易日快照做**透明、可解释**的规则打分（0-100），并按分数
排序输出 Top-K 候选。分数衡量的是"技术形态强度"，**不是涨停概率**。

## 重要前提（务必如实转达用户）
没有任何方法能可靠预测涨停。本打分只是把技术信号量化为可审计的分数，帮助
**缩小关注范围**。最终研判须由 agent 结合新闻、题材、资金面、大盘环境综合
判断，并明确告知用户这只是研究参考、非投资建议。

## 何时使用
- "今天有哪些值得关注的股票" / "帮我选股" / "给涨停候选打分"

## 用法

```bash
# 输出 Top-K 候选（默认读 config 的 model.top_k）
python .claude/skills/astock-screen/scripts/score.py

# 指定数量与某一交易日
python .claude/skills/astock-screen/scripts/score.py --top-k 15 --as-of 2026-06-01
```

输出每只候选的总分与**分项明细**，便于 agent 解释"为什么入选"。

## 规则
- 分数仅基于历史技术形态，无未来信息。
- agent 应在脚本输出之上叠加：相关新闻/题材是否配合、是否有重大风险事件、
  大盘环境，再给出有保留的结论，并始终附风险提示。
